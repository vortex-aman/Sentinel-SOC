# 📖 Sentinel SOC - Introduction

## Overview

Sentinel SOC is a hands-on Security Operations Center (SOC) home lab designed to simulate real-world cyber attacks and strengthen Blue Team skills.

The project uses Wazuh SIEM, Sysmon, Windows 11, Ubuntu Server, and Kali Linux to collect security telemetry, detect malicious activity, and investigate security incidents.

---

## Project Goals

The primary objectives of this project are:

- Build a realistic SOC home lab
- Monitor Windows endpoints
- Detect malicious behavior using Wazuh
- Collect detailed logs with Sysmon
- Simulate cyber attacks from Kali Linux
- Develop custom detection rules
- Map detections to the MITRE ATT&CK Framework
- Practice incident response and investigation

---

## Technologies Used

- Wazuh SIEM
- Sysmon
- Windows 11
- Ubuntu Server
- Kali Linux
- VirtualBox
- MITRE ATT&CK Framework
